# TEAM-DECODE Workspace Rules

## Analysis & External AI Prompt Workflow (Standard Protocol)

เมื่อผู้ใช้ขอให้ **วิเคราะห์ระบบ / ตรวจสอบว่าขาดเหลืออะไร / เตรียม Script สำหรับ External AI** ให้ทำตามลำดับนี้เสมอ:

### Step 1 — ตรวจสอบโค้ดจริงก่อนเสมอ (Verify Before Claiming)
- **อ่านไฟล์จริงทุกตัว** ที่เกี่ยวข้อง (`decoders/*.py`, `core/*.py`, `TEAM-DECODE.py`) ก่อนสรุปว่าอะไรขาด
- ใช้ `grep_search` หรือ `view_file` เพื่อยืนยัน — **ห้ามเดาหรือสรุปจากความจำ**
- รัน `python -B -c "import decoders; ..."` เพื่อดู DECODER_REGISTRY จริงถ้าจำเป็น

### Step 2 — สรุปตาราง "มีแล้ว vs ยังขาด" (Summary Table)
หลังตรวจสอบจริงแล้ว ให้แสดงตารางสรุปชัดเจน:
```
| ฟีเจอร์ | สถานะ | หมายเหตุ (ไฟล์/บรรทัดที่พบ) |
|---|---|---|
| XYZ | ✅ มีแล้ว | decoders/ciphers.py บรรทัด 172 |
| ABC | ❌ ยังขาด | ต้องเพิ่ม |
```

### Step 3 — เตรียม External AI Prompt Scripts (เฉพาะฟีเจอร์ที่ขาดจริงๆ)

สำหรับแต่ละฟีเจอร์ที่ยังขาด ให้สร้าง Prompt แบบนี้:

1. **📂 ไฟล์ที่ต้องส่งให้ AI** — ระบุชัดว่าต้องส่งไฟล์ไหนเป็น context
2. **📋 Prompt พร้อม copy** — ใส่ใน code block ``` ``` ``` ครอบ พร้อม:
   - บริบทของโปรเจกต์ (pattern, imports ที่มีอยู่)
   - รายละเอียดฟีเจอร์ที่ต้องการอย่างละเอียด (logic, guard conditions, edge cases)
   - Constraints (ห้าม raise exception, return None หากไม่ match, ฯลฯ)
   - บอกให้ AI return เฉพาะส่วนที่ต้องการ (append / full file)
3. **📌 วิธีนำไปใช้** — บอกว่า: append ต่อท้าย / วางทับทั้งไฟล์ / สร้างไฟล์ใหม่

### Step 4 — ระบุลำดับความสำคัญ (Priority Table)
```
| ลำดับ | งาน | ความสำคัญ | ไฟล์เป้าหมาย |
```

### Step 3.5 — Protocol สำหรับส่งให้ External AI แบบมีขั้นตอนและไฟล์แนบชัดเจน
เมื่อเตรียม Script หรือ Prompt สำหรับ External AI Chat ให้ปฏิบัติตามลำดับนี้เสมอ:

1. **ส่งให้ AI รู้ก่อนว่า Script นี้คืออะไรและต้องการอะไร**
   - เริ่มด้วยข้อความที่อธิบายว่าสคริปนี้คืออะไร
   - บอกว่าเราต้องการให้ AI ช่วยแก้ไข/เติม/ปรับแต่งบางส่วนของโปรเจกต์
   - ระบุว่าเดี๋ยวจะแนบไฟล์ให้ก่อน โปรดรอ

2. **บอกให้ AI ทราบว่าไฟล์อะไรต้องแนบ**
   - ระบุชัดเจนว่า “ฉันต้องเอาไฟล์ไหนไปให้ AI chat ด้านนอกแก้ไข”
   - ใส่ลิสต์ไฟล์ที่จำเป็นจาก workspace ปัจจุบัน

3. **เตรียม Script ให้อ่านง่ายและพร้อมคัดลอกทันที**
   - เตรียม Script แบบละเอียดที่สุดเท่าที่จะทำได้
   - ให้พร้อมคัดลอกทั้งก้อนมาแทนได้เลยโดยไม่ต้องคิดต่อ

ข้อความที่แนะนำ:
> นี้คือ Script ที่ฉันเตรียมไว้ให้คุณช่วยแก้ไขในโปรเจกต์นี้ก่อนนะ
> เดี๋ยวฉันจะแนบไฟล์ปัจจุบันไปให้ตามลิสต์ก่อน โปรดรอ
>
> ไฟล์ที่ต้องแนบสำหรับการแก้ไขนี้:
> - [ไฟล์ 1]
> - [ไฟล์ 2]
>
> ฉันจะเตรียมสคริปไว้ให้คุณอ่านและคัดลอกทั้งก้อนมาแทนได้เลย

ข้อสำคัญ:
- ก่อนส่งคำสั่งให้ AI ภายนอก ต้องแนบไฟล์ปัจจุบันตามลิสต์ที่ระบุไว้ก่อน
- การแนบไฟล์จริงจาก workspace ปัจจุบันเป็นสิ่งจำเป็นเพื่อให้ AI เข้าใจสถานะจริงของโปรเจกต์ และไม่เดา/สรุปจากความจำ
- ถ้าไม่มีไฟล์ที่แนบจริง AI จะไม่สามารถเข้าใจสถานะของโปรเจกต์ได้อย่างถูกต้อง

## External AI Prompt & File Export Protocol

**ใช้กฎนี้เฉพาะเมื่อผู้ใช้บอกชัดเจนว่าต้องการนำงานไปทำที่ External AI Chat (เช่น ChatGPT, Claude) เท่านั้น**
ถ้าผู้ใช้แค่ขอพัฒนา/แก้ไขฟีเจอร์ — ให้ดำเนินการโดยตรงได้เลย ไม่ต้องสร้าง Prompt สำหรับ AI ภายนอก

เมื่อผู้ใช้ระบุว่าต้องการใช้ External AI Chat:

1. **Do NOT ask the user to copy the entire codebase.**
2. **Identify Target Files**: Specify the exact minimal file(s) needed (e.g., `decoders/ciphers.py`, `core/heuristics.py`).
3. **Generate Custom Prompt**: Provide a ready-to-copy prompt formatted specifically for the requested feature/edit.
4. **Replacement Guidance**: Clearly instruct the user which file to paste the result back into to replace the content cleanly.

## Preferred External AI Workflow (This Repo)
เมื่อผู้ใช้ต้องการให้ External AI Chat แก้ไขโปรเจกต์นี้ ให้ใช้รูปแบบต่อไปนี้เสมอ:

### 1) อย่าให้ AI สร้างไฟล์ใหม่โดยไม่จำเป็น
- ไม่ต้องสร้างไฟล์ใหม่ใน workspace
- ให้เตรียม Prompt/Script แบบละเอียดมาก ๆ ที่บอกงานชัดเจนแล้ว
- ให้ AI แก้ไขไฟล์ที่มีอยู่ตาม content ที่ผู้ใช้แนบมา

### 2) ส่ง Script ที่มีโครงสร้างชัดเจนและละเอียดลึก
Prompt สำหรับ External AI ควรประกอบด้วยส่วนต่อไปนี้:
- ภาพรวมของระบบ (system overview) — อธิบายว่าโปรเจกต์นี้เป็นอะไร, ทำงานอย่างไร, มีโครงสร้างหลักอย่างไร
- บริบทของงาน — อธิบายว่าปัญหาที่ต้องแก้นี้เกี่ยวข้องกับส่วนใดของระบบและมีผลต่ออะไรบ้าง
- วัตถุประสงค์ของงาน — ระบุว่าต้องการให้ระบบดีขึ้นในมิติใด เช่น robustness, accuracy, false-positive reduction, compatibility
- รายละเอียดปัญหาที่ต้องแก้ — อธิบายผลลัพธ์ที่เป็นปัญหาและสถานการณ์ตัวอย่างที่ควรพิจารณา
- คำแนะนำเกี่ยวกับโค้ดปัจจุบันและความคาดหวัง — ระบุว่าโครงสร้างเดิมอยู่ที่ไหนและควรปรับอย่างไร
- ข้อจำกัดของระบบ — เช่น อย่าทำให้ระบบพัง, อย่าล้มใน input ที่ไม่มาตรฐาน, อย่าทำให้ feature อื่นเสียหาย
- รายการไฟล์ที่ต้องแนบก่อนแก้ไข — ระบุไฟล์ที่จำเป็นจริงจาก workspace
- รูปแบบคำตอบที่ต้องการกลับมา — บังคับให้ AI ส่งโค้ดกลับมาแบบ full file หรือ patch ที่สามารถอัปเดตได้ทันที

### 2.1) บังคับให้ใส่ภาพรวมของระบบใน Prompt
เมื่อเตรียม Script สำหรับ External AI ให้แนบส่วนภาพรวมระบบไว้เสมอ โดยสรุปอย่างน้อยดังนี้:
- โปรเจกต์นี้คืออะไร
- มีไฟล์หลักอะไรบ้าง
- ระบบ decode ทำงานผ่าน engine / heuristics / decoders อย่างไร
- ปัจจุบันมีจุดอ่อนอะไรบ้างที่ควรระวัง
- งานที่ต้องแก้ควรทำโดยไม่สร้างไฟล์ใหม่และไม่กระทบ feature อื่นมากเกินไป
- จุดสำคัญคือให้ AI เข้าใจว่าเราไม่ได้ต้องการแค่คำตอบสั้น ๆ แต่ต้องการแก้ไขที่มีโครงสร้างและสามารถถอดกลับมาใช้ได้จริง

### 2.2) คำแนะนำเชิงลึกสำหรับ Prompt ที่ละเอียด
Prompt ควรยึดหลักต่อไปนี้:
- เริ่มด้วยคำอธิบายแบบ "นี่คือโปรเจกต์อะไรและปัญหาคืออะไร"
- ระบุว่าเราให้ AI ทำงานในไฟล์ที่มีอยู่แล้ว ไม่ใช่สร้างไฟล์ใหม่
- ระบุว่าเป็นปัญหาในระบบจริง ไม่ใช่คำสั่งทดลองเล่น
- ระบุตัวอย่าง input/output ที่ควรพิจารณา
- ระบุสิ่งที่ต้องหลีกเลี่ยง เช่น false positive, regression, breaking CLI
- บังคับให้ AI ส่งโค้ดกลับมาในรูปแบบที่พร้อมวางกลับเข้าไฟล์เดิม

### 2.3) รูปแบบของ Prompt ที่แนะนำใน repo นี้
สำหรับ repo นี้ควรใช้ Prompt ที่มีลำดับดังนี้:
1. สรุปภาพรวมระบบ
2. อธิบายปัญหาที่ต้องแก้
3. ระบุไฟล์ที่เกี่ยวข้อง
4. ระบุข้อจำกัดและความปลอดภัย
5. ระบุสิ่งที่ต้องการให้ AI ส่งกลับมา
6. บอกให้ AI เริ่มจากแนบไฟล์จริงก่อน แล้วค่อยแก้ไข

### 3) บังคับให้แนบไฟล์จริงก่อนแก้ไข
ก่อนให้ AI ดำเนินการ ต้องระบุชัดเจนว่าไฟล์อะไรที่ต้องแนบจาก workspace ปัจจุบัน
คำแนะนำที่ใช้บ่อย:
> เดี๋ยวฉันจะแนบไฟล์ปัจจุบันให้คุณก่อน เพื่อให้คุณเข้าใจสถานะจริงของโปรเจกต์ก่อน

### 4) ให้ AI ส่งกลับมาในรูปแบบที่ง่ายต่อการวางกลับ
เมื่อ AI ทำงานเสร็จ ให้คาดหวังให้ส่งกลับมาในรูปแบบต่อไปนี้:
- แก้ไขทั้งหมดแบบเต็มไฟล์ (full file replacement)
- หรือแท็กบล็อกโค้ดที่ต้องแทนที่
- ห้ามให้ AI อธิบายแค่แบบสรุปโดยไม่ให้โค้ดกลับมา

### 5) รูปแบบที่ผู้ใช้ต้องการใน repo นี้
รูปแบบที่ชอบใน repo นี้คือ:
- สร้าง Script/Prompt สำหรับ AI ภายนอกแบบละเอียดมาก ๆ
- บอกว่า “ฉันจะแนบไฟล์ปัจจุบันไปให้ก่อน โปรดรอ”
- ระบุไฟล์ที่ต้องแนบชัดเจน
- ให้ AI ทำงานจากไฟล์ที่แนบมาโดยตรง
- เมื่อ AI เสร็จ ให้คัดลอกโค้ดกลับมาใส่ในช่องแชทแบบง่าย ๆ เพื่อวางกลับได้ทันที

## Backup Directory Rule

- Files inside the `backup/` directory are for archival purposes.
- **Do NOT inspect or read files inside `backup/`** during regular development sessions unless explicitly requested by the user or strictly necessary for critical bug repairs.
